## 一、工作一：质量数据可信治理与评价

### A. 数据标准与语义互操作

**研究背景与现状**

- 智能制造推进中，**设备语义互联不足**成为智能工厂建设瓶颈；跨系统数据共享的关键在于构建**语义一致的设备信息模型**（ISO/IEC 标准框架强调统一且可互操作的信息模型）。
- **OPC UA** 已成为工业界主流：跨平台、厂商无关，提供统一建模框架与地址空间；但在数控机床等场景仍大量依赖**手工建模**，效率低、一致性差。
- 现有 OPC UA 信息模型自动构建研究主要有三条路线：
  1. **模型→代码编译链**（如 open62541 nodeset_compiler）：仍需手工维护 XML，无法一键映射属性数据；
  2. **商业建模工具**（SiOME、UaModeler）：缺少网状视图、语义一致性校验、版本管理与自动纠错；
  3. **Excel→XML 脚本映射**：多为一次性脚本，缺乏交互式纠错与一致性校验，可维护性不足。

**相关技术**

| 技术 | 说明 | 代表文献 |
|------|------|----------|
| OPC UA 信息模型 / NodeSet2 | 工业设备语义建模与互操作 | 陈乾《OPC UA信息模型自动构建方法的研究与实现》 |
| Flatten-Build + ConsCheck | 语义一致性校验与自动修复 | 同上 |
| Excel→NodeSet2 零脚本映射 | 结构化表驱动自动建模 | 同上 |
| ISO 8000 / IEC 62424 / GB/T 34960.5 | 数据质量与过程数据标准体系 | 申报书 §1.1；参考文献 [01]–[07] |

**对本项目的启示**：工作一需先解决雷达整机/软件/元器件数据的**字段、单位、时间戳、对象编码**统一，再谈治理与评价；OPC UA 思路可借鉴于「质量对象信息模型」设计。

### B. 多模态/异构数据治理与清洗

**研究背景与现状**

- **卫星在轨试验数据**：空间环境复杂导致质量良莠不齐；传统方法对野值剔除多用模糊法、离群点分析、线性回归，但线性假设、异常值敏感、阈值主观等问题突出；缺失值处理需考虑多变量层级结构。
- **海量异构数据**（物联网/电商/信息化平台）：结构化与非结构化并存，单目标嵌入清洗难以定向整合。已有方法包括：选权迭代样本清洗（清洗目标一致性不足）、PSL 模糊规则+神经网络（边缘目标识别模糊）、BPNN+SVM 多源融合（特征提取与决策难同步）等，普遍存在**清洗稳定性与精度不足**。
- **多模态数据治理**（罗洪佳）：文本/图像/音频/视频等格式与语义差异大，传统单模态系统难以跨模态协同；需统一语义空间、元数据管理与质量检测。

**相关技术**

| 技术 | 适用场景 | 代表文献 |
|------|----------|----------|
| SVR 边界带野值剔除 | 连续/离散野值、非线性边界 | 吕道桓《卫星在轨试验数据预处理方法研究》 |
| 混合效应完全条件插补 | 多变量层级缺失填补 | 同上 |
| 密度分层约减 + 改进 LSTM | 海量异构数据清洗与一致性校验 | 单孟雪《基于改进LSTM神经网络的海量异构数据清洗方法》 |
| 多 Agent 分层治理架构 | 多模态接入、清洗、元数据、检索一体化 | 罗洪佳《多Agent协作的多模态数据治理与检索一体化系统设计》 |
| RANSAC / 半监督异常检测 / 稀疏表示 | 风电、高维流数据清洗 | 参考文献 [08]–[16] |

**对本项目的启示**：SECOM/C-MAPSS 等本地数据对应 **B 阶段**（缺失填补、异常检测、特征筛选）；治理结果应输出**可信度指标**供工作三使用。

### C. 数据质量综合评价

**研究背景与现状**

- 现有 DQA 方法多从**单一数据质量维度（DQD）**的基本概念出发，忽略**细粒度子维度**及相关性对评估结果的影响。
- 工业**多元时序数据**在完整性、规范性、一致性、唯一性、准确性等维度上表现复杂，需要子维度权重与相关性建模，才能得到可操作的 DQ 诊断结果。

**相关技术**

| 技术 | 说明 | 代表文献 |
|------|------|----------|
| IMTSDQA 细粒度子维度评估 | 完整性/规范性/一致性/唯一性/准确性及其子维度 | 宋洪涛《工业多元时序数据质量评估方法》 |
| 熵权 + TOPSIS / 模糊综合评价 | 多指标综合排序 | 参考文献 [06][19]；申报书 Lasso-FCE |
| 灰色关联 + 证据融合 | 指标关联与等级输出 | 申报书 §1.3 |
| IoT 自适应加权融合评估 | 多源估计融合质量分 | 参考文献 [02] |

**对本项目的启示**：工作一输出不仅是「洗干净的数据」，还要有**面向整机/软件/元器件差异化对象的质量评分**，并与后续风险模型联动。

### D. 时序缺失补全与不确定性表达（数据治理延伸）

**研究背景与现状**（周立等综述，2025）

- 时序数据在工业、金融、交通、医疗等领域普遍存在；采集、传输、存储过程中因传感器故障、人为遗漏、隐私保护等导致**高比例缺失**（如 PhysioNet2012 缺失率约 80%），严重影响下游预测与决策。
- 方法演进：**统计填补**（均值/ARIMA）→ **机器学习**（KNN、矩阵分解）→ **深度学习**（RNN/CNN/Transformer/GAN/扩散/GNN）→ **大模型预训练补全**（泛化到未见数据）。
- 深度学习补全方法可按骨干分为四类：基于 RNN、CNN、注意力机制、大模型；性能受**缺失机制、缺失模式、缺失率、变量数、序列长度**显著影响；补全误差降低**未必**线性转化为下游任务提升。
- 健康评估领域：传统故障诊断依赖足够故障样本；**健康基准模型（HBM）**用正常状态监测数据学习健康行为，通过偏差量化劣化；图卷积、异构图对比学习可挖掘时空依赖，但计算复杂度高；**蒙特卡洛 Dropout** 等用于输出不确定性区间。

**相关技术**

| 技术 | 说明 | 代表文献 |
|------|------|----------|
| 深度学习时序补全四类范式 | RNN/CNN/Attention/LLM | 周立《基于深度学习的不完整时序数据补全方法综述》 |
| 时空耦合学习 + MC Dropout 不确定性 | 健康振动区间上界、PDI 指数 | 马驰《融合时空耦合学习与不确定性量化的抽水蓄能机组健康状态评估》 |
| 贝叶斯神经网络不确定性 | 预测均值+方差，支持可信决策 | 杨彪《基于贝叶斯网络的行人穿越不确定性量化研究》（方法可迁移） |
| 时空扩散 / 共形预测 | 申报书 §1.2.2–1.2.3 目标技术 | 申报书；参考文献 [16] |

**对本项目的启示**：C-MAPSS 类退化数据对应 **D 阶段**（缺失补全 + RUL 相关不确定性）；治理层应输出**补全置信度/区间**，而非点估计 alone。

## 二、工作二：质控知识图谱与差异化根因追溯

### E. 知识图谱构建与增量更新

**研究背景与现状**

- 知识图谱已广泛用于推荐、问答、**智能运维**等场景，但工业领域面临：**标注样本稀缺、文档多源异构、语义结构复杂**。
- 增量构建难点：新文档引入的实体/关系与已有图谱的对齐、冗余与错误关系过滤、版本一致性与可演化性。
- 大模型时代路径：用 GPT-4 等生成高质量标注样本 → **LoRA 微调**轻量模型做实体关系抽取 → **向量库 Top-k 召回** + LLM 语义一致性筛选 → 融合入 Neo4j 等图库；风电等装备领域已有 BOM 层级 + 图谱可视化实践。

### F. 根因追溯与图推理

**研究背景与现状**

- 水电站等大型装备故障**成因复杂、关联性强**；传统人工巡检费时费力、易漏检。
- 基于知识图谱的故障诊断：融合专家经验与历史故障数据；采用 **Noisy-Or 近似推理**实现根因定量分析；结合图推理与**熵理论**优化排查建议排序。
- 系统优点：可不依赖大量历史数据、可解释性强、支持人机交互式排查、可动态更新。

### G. 分析树/关键事件与图谱融合

**研究背景与现状**

- 高端装备结构复杂，失效往往由**关键事件**在机电热等多物理场耦合中触发；单纯故障诊断依赖样本，难以预警。
- 故障知识分层建模：基于**故障树/故障机理**分层构建知识本体；非结构化文档经 **Word2vec + BiLSTM-CRF** 抽取实体关系；R2RML 映射 + Levenshtein/Jaccard 融合保证知识一致性。
- **失效关键事件辨识**：统计失效事件概率 → 嵌入部件重要度 → **改进 PageRank（IPR）** 量化节点活跃度，识别影响退化过程的关键事件；在航空发动机等系统上验证优于传统 PageRank。

## 三、工作三：质量风险预测与智能协同管控

### H. 无监督/少样本异常检测与故障识别

**研究背景与现状**

- 滚动轴承等关键部件：传统 RF/SVM 难提取有效特征；CNN/自编码器成为主流。
- 自编码器局限：易过拟合、跨负载泛化不足；注意力机制可强化关键通道但可能忽略全局信息。
- 工业现场常见**无标签、少样本**场景，需要无监督异常检测 + **异常推断**（定位异常变量/时段）。

### I. 健康评估、剩余寿命与预测不确定性

**研究背景与现状**

- 旋转机械健康评估：从「故障诊断」转向「**健康基准 + 偏差度量**」；需处理工况切换、水电磁耦合、劣化缓慢、故障样本稀缺等问题。
- 不确定性量化：纯点预测无法支撑维保决策；**贝叶斯深度学习**、MC Dropout 等可提供预测区间与可信度。
- 不完整时序补全与预测联合：补全质量直接影响 RUL/风险预测（见板块 D）。

### K. 多智能体协同与分布式决策（平台层）

**研究背景与现状**

## 五、各板块研究现状一句话总结（可直接用于论文绪论）

1. **数据标准**：工业界仍以手工 OPC UA 建模为主，自动构建与语义校验是热点，但面向**装备质量全生命周期**的统一规范仍不足。  
2. **数据治理**：野值剔除、异构清洗、多模态协同治理已有较多方案，但缺少与**风险识别效果联动**的评价闭环。  
3. **质量评价**：从粗粒度 DQD 向细粒度子维度、相关性建模发展；差异化对象（整机/软件/元器件）的统一评价框架仍少。  
4. **时序补全**：深度学习与大模型补全快速演进，但缺失机制敏感、下游任务增益不确定；**不确定性输出**逐渐与健康评估结合。  
5. **知识图谱**：LLM+LoRA+向量对齐的增量构建成为工业 KG 主流路径；本体约束与版本管理仍是工程难点。  
6. **根因追溯**：图谱+概率推理+熵排序在能源装备中验证有效；**电子信息装备层级传播**需专门本体与路径算法。  
7. **关键事件**：故障知识图谱与改进 PageRank 结合，适合识别「关键质量节点」。  
8. **风险预测**：无监督/自编码器/健康基准模型成熟，但**知识驱动 + 大模型解释**的组合研究在本地文献库中仍薄弱。  
9. **智能体协同**：多 Agent 用于数据治理的平台架构可借鉴；**质控领域轻量三类 Agent 闭环**尚缺公开对标文献。
