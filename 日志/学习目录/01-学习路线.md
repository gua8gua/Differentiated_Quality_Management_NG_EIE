# 零基础学习路线

> 从「看懂申报书」到「能做小型原型、参与平台实现」的分阶段目录。  
> 关键词检索见 [领域关键词索引](../04-领域关键词索引.md)；工作划分见 [申报书技术方案](../01-申报书技术方案.md)。

---

> 学习目标：从“看懂申报书”逐步过渡到“能拆解技术方案、能做小型原型、能参与平台实现”。建议每个阶段都留下学习笔记、术语卡片和一个可运行的小练习。

### 阶段0：项目全貌与术语入门

**目标**：先知道项目要解决什么问题，不急着深入算法。

**应学习的知识条目**：
- 新一代电子信息装备、整机、软件、元器件的基本含义
- 质量管控、质量风险、故障检测、根因追溯、闭环改进
- 全生命周期：论证、设计、研制、生产、测试、交付、运维、退役
- 三类质量管控对象：整机质量、软件质量、元器件质量
- 项目主线：数据汇聚 -> 数据治理 -> 知识图谱 -> 风险识别/预测 -> 智能体协同 -> 决策平台
- 申报书核心章节阅读顺序：研究目标 -> 研究内容 -> 技术方案 -> 考核指标

### 阶段1：计算机与编程基础

**目标**：具备后续实现算法和平台原型的基本编程能力。

**应学习的知识条目**：
- Python基础：变量、函数、类、模块、异常处理、文件读写
- 常用数据结构：列表、字典、集合、元组、DataFrame
- 环境管理：Anaconda/venv、pip、requirements.txt
- Jupyter Notebook基础使用
- Git基础：仓库、提交、分支、差异对比
- Markdown写作：标题、列表、表格、代码块、Mermaid流程图
- 基础工程习惯：命名规范、日志输出、配置文件、可复现实验

### 阶段2：数据分析与机器学习基础

**目标**：能处理表格数据和时序数据，理解模型训练的基本流程。

**应学习的知识条目**：
- NumPy、Pandas、Matplotlib/Seaborn基础
- 数据读取、清洗、统计描述、缺失值统计、异常值观察
- 训练集/测试集、特征、标签、监督学习、无监督学习
- 常见模型：线性回归、逻辑回归、决策树、随机森林、K-means
- 模型评价：准确率、召回率、F1、AUC、均方误差、混淆矩阵
- 过拟合、欠拟合、交叉验证、特征标准化
- 机器学习工具：scikit-learn基础流程

### 阶段3：装备质量管理与数据标准

**目标**：理解项目为什么首先强调数据标准和全生命周期质量数据。

**应学习的知识条目**：
- 质量管理基础：QMS、质量指标、质量问题单、质量闭环
- 电子信息装备质量数据类型：传感器信号、测试记录、维修日志、检测图像、设计文档
- 数据质量五维：正确性、完整性、时效性、一致性、可解释性
- 元数据、数据字典、术语标准、分类编码、数据交换格式
- ISO 8000、IEC 62424、GB/T 34960.5的基本概念
- 全生命周期质量数据采集与管理流程
- 数据孤岛、语义歧义、互操作性问题

### 阶段4：多模态质量数据治理

**目标**：能实现质量数据清洗、异常检测、缺失补全和标注的基础版本。

**应学习的知识条目**：
- 数据预处理：去重、类型转换、单位统一、Z-score归一化
- 特征筛选：方差筛选、相关性筛选、Lasso特征选择
- 异常检测：3σ原则、箱线图/IQR、孤立森林、One-Class SVM
- 时间滑动窗口思想和软阈值异常检测
- 缺失数据处理：均值/中位数填充、插值、KNN补全、模型补全
- 多变量时间序列基础：窗口切分、滞后特征、趋势和周期
- 多模态数据：文本、表格、图像、时序信号的基本组织方式
- 人机协同标注、主动学习、LLM辅助标注的基本流程

### 阶段5：质量评价与多准则决策

**目标**：能构建一个小型质量评价指标体系，并计算综合评价结果。

**应学习的知识条目**：
- 指标体系设计：一级指标、二级指标、指标权重、评价等级
- 层次分析法AHP：判断矩阵、一致性检验、权重计算
- 熵权法、CRITIC、主客观组合赋权
- 灰色关联分析GRA：关联度、参考序列、比较序列
- D-S证据理论：证据、信任度、冲突融合
- 模糊综合评价FCE：评语集、隶属度函数、模糊矩阵
- Lasso特征提取与评价指标降维
- 雷达图、评分卡、评价报告生成

### 阶段6：时序故障检测、健康评估与寿命预测

**目标**：能对装备运行时序数据做异常检测、健康度分析和简单寿命预测。

**应学习的知识条目**：
- 时间序列基础：趋势、周期、残差、平稳性、滑动窗口
- STL分解、动态时间规整DTW、时序相似性检索
- 自编码器AE、Seq2Seq、GRU/LSTM基础
- 基于重构误差的故障检测方法
- CNN-LSTM时序建模思路
- GAF、MTF、递归图等“时序转图像”方法
- 对比学习、自监督学习、少样本故障检测
- 剩余寿命RUL、退化过程、Wiener过程基础概念

### 阶段7：知识图谱与知识工程

**目标**：能把质量文本、故障记录、标准规范转成可查询、可推理的结构化知识。

**应学习的知识条目**：
- 知识图谱基本概念：实体、关系、属性、三元组
- 领域本体：概念层级、关系约束、质量语义建模
- 命名实体识别NER：BIO标注、BERT-BiLSTM-CRF基本思路
- 关系抽取：实体对、关系类型、提示学习
- 实体对齐、知识融合、冲突消解
- Neo4j基础：节点、边、属性、Cypher查询
- 图谱推理：路径查询、影响传播、根因追溯
- 知识动态更新：增量更新、版本管理、知识库维护

### 阶段8：大模型、RAG与质控领域模型

**目标**：理解申报书中“大模型+RAG”如何用于质量风险预测和智能问答。

**应学习的知识条目**：
- 大语言模型基础：Token、上下文、提示词、幻觉问题
- 常见开源模型：Qwen、DeepSeek等的使用方式
- Embedding和向量数据库：文本切分、向量化、相似度检索
- RAG流程：文档分块 -> 向量检索 -> 重排序 -> 上下文增强 -> 生成答案
- 领域知识注入：质控知识库、历史案例库、标准规范库
- LoRA微调、指令微调、模型蒸馏的基本概念
- GraphRAG和知识图谱增强问答
- 时序数据与文本提示融合：统计特征、相似片段、STL分解结果转提示词

### 阶段9：三类质量管控智能体

**目标**：能理解并设计整机、软件、元器件三类智能体的职责、输入、输出和协同关系。

**应学习的知识条目**：
- 智能体基本结构：感知、记忆、规划、执行
- 多智能体系统MAS：角色分工、通信机制、任务协同
- 整机质量管控智能体：质量指标分解、全局决策共享、可靠性评估
- 软件质量管控智能体：接口耦合、功能逻辑、风险可追溯
- 元器件质量管控智能体：参数漂移、微观缺陷、机理可解释
- Top-Down指标分解与Bottom-Up风险反馈
- 博弈论、共识算法、冲突消解的基本思想
- 智能体输出物：风险预警、根因分析、处置建议、质量报告

### 阶段10：平台工程与系统实现

**目标**：能参与搭建“电子信息装备质量管控智能决策管理平台”的原型。

**应学习的知识条目**：
- Web后端基础：FastAPI/Flask、REST API、请求与响应
- 数据库基础：MySQL表设计、索引、事务、SQL查询
- 图数据库集成：Neo4j连接、Cypher查询接口
- 文件与多模态数据管理：本地文件、对象存储、FastDFS概念
- 前端基础：HTML/CSS/JavaScript、Vue或React基础
- 平台分层架构：感知层、治理层、知识层、模型层、应用层
- 模型服务化：模型加载、推理接口、批处理任务
- 权限管理、审计日志、数据血缘、任务流转
- 可视化：风险列表、趋势图、雷达图、知识图谱展示

### 阶段11：项目原型实践路径

**目标**：把前面知识串起来，完成一个最小可运行版本。

**应学习的知识条目**：
- 选定一个小场景：例如“元器件测试数据异常检测与风险预警”
- 构造或收集样例数据：表格数据、时序数据、故障描述文本
- 完成数据治理：清洗、归一化、异常检测、缺失补全
- 建立质量评价指标：正确性、完整性、时效性、一致性、可解释性
- 构建小型知识图谱：元器件、故障现象、原因、检测方法、处置措施
- 实现RAG问答：根据故障描述检索相关标准、案例和处置建议
- 设计一个智能体流程：输入数据 -> 分析风险 -> 追溯原因 -> 输出建议
- 搭建简单平台界面：上传数据、查看异常、查看图谱、生成报告
- 编写技术文档：需求说明、架构设计、算法说明、测试报告

### 阶段12：论文、专利与项目交付能力

**目标**：具备把实现成果整理成项目材料、论文或专利的基础能力。

**应学习的知识条目**：
- 文献检索：关键词组合、论文筛选、阅读笔记
- 论文结构：摘要、引言、相关工作、方法、实验、结论
- 实验设计：对比方法、消融实验、评价指标、可复现设置
- 专利基础：技术问题、技术方案、有益效果、权利要求
- 软件著作权材料：功能说明、代码整理、界面截图
- 项目报告：年度进展报告、中期报告、测试报告、总结报告
- 第三方测评准备：功能清单、测试用例、部署说明、用户手册

### 建议学习顺序

1. 先完成阶段0-2，保证能看懂项目词汇、会用Python处理数据。
2. 再完成阶段3-6，掌握“质量数据治理、评价、风险检测”这条数据智能主线。
3. 然后完成阶段7-9，学习“知识图谱、大模型RAG、三类智能体”这条知识智能主线。
4. 最后完成阶段10-12，把算法、知识库和智能体整合成可演示的平台原型与交付材料。
