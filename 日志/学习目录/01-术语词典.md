## 一、数据标准与治理

| 缩写/术语 | 全称 / 含义 | 一句话 | 在本项目里 |
|---|---|---|---|
| **IoT** | Internet of Things，物联网 | 设备联网采集数据的系统 | 质量数据来源之一（传感器、产线设备） |
| **ETL** | Extract-Transform-Load | 抽取→转换→加载的数据集成流程 | 多源质量数据汇入平台的标准流程 |
| **ISO 8000** | 国际数据质量标准系列 | 定义如何验证、交换「合格数据」 | 申报书数据标准体系的基础参考 |
| **IEC 62424** | 工业过程控制数据标准 | 过程工业数据表达与交换规范 | 装备/process 类质量数据标准参考 |
| **GB/T 34960.5** | 信息技术服务 治理 第5部分：数据治理规范 | 国标数据治理框架 | 国内数据管理标准依据 |
| **MCDM** | Multi-Criteria Decision Making，多准则决策 | 多个指标下做排序/选优 | 质量评价、供应商评价、管控策略选择 |
| **CEI** | Comprehensive Evaluation Index，综合评估指标 | 把多指标合成一个评价结果 | 装备/数据质量综合打分 |
| **数据治理** | Data Governance | 对数据做规范、清洗、质量管控的一整套管理 | 研究内容 1 核心工作 |
| **多模态** | Multimodal | 多种类型数据（数值、文本、图像、时序） | 装备质量数据的主要形态 |
| **元数据** | Metadata | 描述数据的数据（字段名、来源、时间） | 标准体系、数据目录的基础 |
| **数据孤岛** | Data Silo | 各系统数据互不相通 | 本项目要解决的问题之一 |
| **Z-score** | 标准分数归一化 | 减均值除标准差，统一到可比尺度 | 多指标数据预处理 |
| **3σ 准则** | 三倍标准差法则 | 偏离均值超过 3 倍标准差视为异常 | 传统异常检测（申报书指出其局限） |
| **IQR** | Interquartile Range，四分位距 | 用 Q3-Q1 界定异常的传统统计方法 | 与 3σ 类似的基线异常检测 |
| **RANSAC** | Random Sample Consensus | 随机抽样拟合、剔除离群点的鲁棒算法 | 论文 [8] 风电数据清洗 |
| **LOESS** | Locally Estimated Scatterplot Smoothing | 局部加权回归平滑 | 论文 [9] 多段插值补全 |
| **鲁棒回归** | Robust Regression | 对离群点不敏感的回归方法 | 异常密集场景下的统计建模 |

## 二、综合评价与模糊决策

| 缩写/术语 | 全称 / 含义 | 一句话 | 在本项目里 |
|---|---|---|---|
| **AHP** | Analytic Hierarchy Process，层次分析法 | 把复杂问题分层、两两比较定权重 | 评价指标权重、专家打分结构化 |
| **TOPSIS** | Technique for Order Preference by Similarity to Ideal Solution | 算与理想解/负理想解的距离来排序 | 论文 [19] 公共卫生评价 |
| **熵权法** | Entropy Weight Method | 用信息熵衡量指标离散度定客观权重 | 论文 [5][17][19][20] 常用 |
| **CRITIC** | Criteria Importance Through Intercriteria Correlation | 结合变异性与相关性的客观赋权 | 申报书 1.3.1 组合权重 |
| **FCE** | Fuzzy Comprehensive Evaluation，模糊综合评价 | 用隶属度处理「好/中/差」等模糊判断 | 申报书质量数据评价模型 |
| **D-S 理论** | Dempster-Shafer Evidence Theory，证据理论 | 融合不确定、冲突的多源证据 | 论文 [18]、申报书专家意见融合 |
| **GRA** | Grey Relational Analysis，灰色关联分析 | 衡量指标间相似/关联程度 | 申报书评价指标筛选 |
| **IF** | Intuitionistic Fuzzy，直觉模糊集 | 同时考虑隶属度、非隶属度、犹豫度 | 论文 [19] entropy-TOPSIS-IF |
| **q-ROF** | q-Rung Orthopair Fuzzy Set | 更广义的模糊集，处理高不确定性 | 论文 [6] 电力装备供应商评价 |
| **因子分析** | Factor Analysis | 把多相关变量归纳为少数潜在因子 | 论文 [5] 工业互联网成熟度 |
| **德尔菲法** | Delphi Method | 多轮专家问卷收敛意见 | 论文 [21] 指标验证 |
| **Lasso** | Least Absolute Shrinkage and Selection Operator | 带 L1 正则的回归，自动筛特征 | 申报书 1.3.2 特征提取 |
| **皮尔逊相关** | Pearson Correlation | 衡量两变量线性相关程度 | 指标冗余筛选 |
| **博弈论组合赋权** | Game Theory Combined Weighting | 主客观权重博弈求均衡 | 申报书 1.3.1 权重融合 |

## 三、机器学习与深度学习

| 缩写/术语 | 全称 / 含义 | 一句话 | 在本项目里 |
|---|---|---|---|
| **ML** | Machine Learning，机器学习 | 从数据中自动学规律 | 风险检测、质量预测主线 |
| **DL** | Deep Learning，深度学习 | 多层神经网络的 ML | 时序、图像、文本建模 |
| **BP** | Back Propagation Neural Network | 经典前馈神经网络 | 论文 [28] 电容晶体管可靠性 |
| **CNN** | Convolutional Neural Network，卷积神经网络 | 擅 long 图像/网格特征 | 论文 [33][34]、申报书健康度分析 |
| **LSTM** | Long Short-Term Memory | 擅 long 序列数据的 RNN | 申报书 CNN-LSTM 健康度 |
| **RF** | Random Forest，随机森林 | 多棵决策树集成的 ML 方法 | 论文 [27][31] |
| **XGBoost** | eXtreme Gradient Boosting | 梯度提升树的高效实现 | 论文 [31] 缺陷率预测 |
| **LightGBM** | Light Gradient Boosting Machine | 更快、更省内存的 GBDT | 论文 [31] |
| **GBDT** | Gradient Boosting Decision Tree | 梯度提升决策树 | 集成学习家族 |
| **决策树** | Decision Tree | 按特征分支做分类/回归 | 论文 [33] LED 质量分类 |
| **判别分析** | Discriminant Analysis | 找最佳分类边界 | 论文 [33] |
| **集成学习** | Ensemble Learning | 组合多个模型提高性能 | 工业 QC、缺陷预测常用 |
| **半监督学习** | Semi-Supervised Learning | 少量标签 + 大量无标签训练 | 论文 [11] 异常检测 |
| **自监督学习** | Self-Supervised Learning | 从数据本身构造训练任务 | 申报书寿命预测、对比学习 |
| **对比学习** | Contrastive Learning | 拉近相似样本、推远不相似样本 | 申报书时序反转寿命预测 |
| **Seq2Seq** | Sequence to Sequence | 序列编码再解码的模型结构 | 申报书少样本故障检测 |
| **自编码器** | Autoencoder | 压缩再重建，用重建误差检异常 | 申报书 Seq2Seq 故障检测 |
| **稀疏表示** | Sparse Representation | 用少量基向量表示高维数据 | 论文 [12][13] 特征提取 |
| **特征重要性** | Feature Importance | 模型判断哪些输入最影响输出 | 论文 [31] 缺陷根因诊断 |
| **过拟合** | Overfitting | 模型背训练集、泛化差 | 少样本场景的主要风险 |
| **欠采样** | Undersampling | 减少多数类样本平衡数据 | 论文 [27] 讨论其副作用 |

## 四、时序、可靠性与信号处理

| 缩写/术语 | 全称 / 含义 | 一句话 | 在本项目里 |
|---|---|---|---|
| **时序数据** | Time Series Data | 按时间排列的观测序列 | 装备运行状态、传感器数据 |
| **PHM** | Prognostics and Health Management | 预测与健康管理 | 装备健康度、寿命预测总称 |
| **RUL** | Remaining Useful Life，剩余使用寿命 | 还能用多久 | 申报书寿命预测目标 |
| **Wiener 过程** | Wiener Process | 带随机漂移的退化随机过程 | 论文 [32] 加速退化建模 |
| **加速退化** | Accelerated Degradation Testing | 加速应力下观测退化 | 元器件长寿命试验 |
| **马尔可夫** | Markov Process | 下一状态只依赖当前状态 | 论文 [15] 三态可靠性 |
| **贝叶斯** | Bayesian Method | 用先验+观测更新概率 | 论文 [15] 多源先验融合 |
| **区间预测** | Interval Prediction | 给出预测区间而非单点 | 论文 [16] 压实质量评估 |
| **GAF** | Gramian Angular Field，格拉姆角场 | 时序转图像的一种方法 | 申报书 CNN-LSTM 输入 |
| **MTF** | Markov Transition Field，马尔可夫转移场 | 时序转图像的另一种方法 | 申报书多模态时序描述 |
| **DTW** | Dynamic Time Warping，动态时间规整 | 对齐不同长度/速度的时序 | 申报书 K-means 风险特征 |
| **STL 分解** | Seasonal-Trend decomposition using Loess | 时序拆成趋势/季节/残差 | 申报书大模型风险预测 |
| **CWT** | Continuous Wavelet Transform，连续小波变换 | 提取时频特征 | 申报书缺失数据补全 |
| **共形预测** | Conformal Prediction | 给出有统计保证的置信区间 | 申报书不确定性量化 |

## 五、知识图谱、NLP 与大模型

| 缩写/术语 | 全称 / 含义 | 一句话 | 在本项目里 |
|---|---|---|---|
| **KG** | Knowledge Graph，知识图谱 | 实体+关系的结构化知识网络 | 质控知识库核心 |
| **NER** | Named Entity Recognition，命名实体识别 | 从文本中找出关键对象 | 图谱构建第一步 |
| **CRF** | Conditional Random Field，条件随机场 | 序列标注的全局优化模型 | BERT-BiLSTM-CRF 实体识别 |
| **BERT** | Bidirectional Encoder Representations from Transformers | 预训练语言模型 | 申报书实体/关系抽取 |
| **BiLSTM** | Bidirectional LSTM | 双向读文本的序列模型 | 与 BERT、CRF 组合 |
| **关系抽取** | Relation Extraction | 识别实体间语义关系 | 构建三元组（头-关系-尾） |
| **三元组** | Triple | (主体, 关系, 客体) 知识单元 | 图谱最小存储单位 |
| **本体** | Ontology | 领域概念及关系的规范定义 | 申报书语义约束 |
| **RAG** | Retrieval-Augmented Generation，检索增强生成 | 大模型回答前先查知识库 | 申报书风险预测、智能体 |
| **LLM** | Large Language Model，大语言模型 | 大规模预训练文本模型 | DeepSeek/Qwen 等基座 |
| **LoRA** | Low-Rank Adaptation | 低秩微调，省算力适配大模型 | 申报书小样本多模态补全 |
| **GNN** | Graph Neural Network，图神经网络 | 在图结构上做深度学习 | 申报书策略推荐 |
| **Neo4j** | 图数据库产品名 | 存图谱、做路径查询 | 申报书知识库存储 |
| **向量检索** | Vector Retrieval | 用 embedding 相似度找相关文档 | RAG 的检索环节 |
| **提示学习** | Prompt Learning | 用提示模板引导模型完成下游任务 | 申报书关系抽取 |
| **蒸馏** | Knowledge Distillation | 大模型压缩到小模型 | 申报书垂类模型轻量化 |
