# §1.3 综合评价与决策方法

> 申报书章节：**§1.3 质量数据评价方法研究**（1.3.1–1.3.2） | 主要论文：[17]–[25]

---

## 1. 这个领域在学什么

当有很多评价指标、专家意见不一致、信息模糊时，如何**科学、公平、可解释**地给出综合结论——既评「数据质量」，也评「模型/研究质量」。

---

## 2. 核心概念

### 2.1 多准则决策（MCDM）

多个指标下排序或选优。常见流程：定指标 → 定权重 → 合成得分。

### 2.2 客观赋权

- **熵权法**（[17][19][20]）：指标差异越大，权重越高。
- **CRITIC**（申报书）：同时看变异性与指标间冲突。
- **最大熵-最小残差**（[17]）：优化意义下的组合赋权。

### 2.3 主观赋权与结构化专家意见

- **AHP 层次分析法**（[21]）：分层两两比较。
- **德尔菲法**（[21]）：多轮专家问卷收敛。

### 2.4 模糊与证据

- **模糊综合评价 FCE**（申报书）：「较好/一般/较差」等模糊语言量化。
- **D-S 证据理论**（[18]）：融合冲突、不确定的多源证据。
- **直觉模糊 TOPSIS**（[19]）：IF + TOPSIS 处理犹豫度。

### 2.5 质量评估框架（方法论借鉴）

- **QUADAS-3**（[22][23]）：诊断准确性研究的偏倚评估——强调「评价工具也要靠谱」。
- **QUAIDE**（[24]）：AI 诊断研究质量评估清单。
- **AI 预测模型五项准则**（[25]）：预测模型质量的关键维度。

### 2.6 知识图谱 + 评价（[20]）

用知识图谱辅助数据资产价值评价，连接 L3 与 L5。

### 3.1 图4：Lasso-FCE 评价流程（§1.3.2）

![图4 Lasso-FCE 质量数据评估](../../../资料/img/04_Lasso模糊综合质量数据评估方法.jpeg)

完整链路：装备多层级指标树 → 数据持久化 → **Lasso** 压缩高维指标并排序 → 专家打分矩阵 → **AHP** 主观权重 → **FCE** 模糊隶属度 → 输出健康/亚健康/故障/失效等级。注意 Lasso 负责「选哪些指标」，AHP+FCE 负责「如何综合打分」，二者分工不同。

数据质量五维：正确性、完备性、时效性、一致性、可解释性。
