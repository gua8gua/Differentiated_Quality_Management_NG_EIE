# §2.2 机器学习与可靠性预测

> 申报书章节：**§2.2 质量问题发现及潜在风险预测技术研究**（2.2.1–2.2.3） | 主要论文：[26]–[34]

---

## 1. 这个领域在学什么

从质量数据里**找出风险、预测故障、估计剩余寿命**——把「事后分析」变成「事前预警」。

---

## 2. 核心概念

### 2.1 传统机器学习

- **随机森林 RF / XGBoost / LightGBM**（[31]）：表格型特征，可解释特征重要性。
- **BP 神经网络**（[27]）：非线性映射，适合中小样本。
- **判别分析**（[28]）：分类边界清晰的问题。

### 2.2 深度学习

- **CNN**（[29][33]）：图像/视觉缺陷检测。
- **LSTM / Seq2Seq**（申报书）：时序序列到序列预测。
- **对比学习**（申报书）：少样本场景增强表征。

### 2.3 时序与信号处理

- **GAF / MTF**（申报书）：一维时序转二维图像供 CNN 使用。
- **CWT 小波**（申报书）：多尺度时频特征。
- **DTW / STL**（[26]）：时序对齐与分解。

### 2.4 可靠性工程

- **Wiener 随机过程**（[32]）：退化建模，估计 RUL（剩余寿命）。
- **FMEA / 风险矩阵**（[26][29]）：结构化风险识别。
- **PHM**（预测与健康管理）：传感器 + 模型 + 决策闭环。

### 2.5 集成与不确定性

- 集成学习降低过拟合（[31]）。
- Wiener 模型给出预测区间（[32]），与 L2 区间预测呼应。

## 3. 在本项目中的应用

| 申报书任务 | L4 方法 |
|---|---|
| 2.2.1 风险识别 | 质量问题分析树、图谱路径匹配 |

| 2.2.3 潜在风险预测 | DTW+STL+大模型 Prompt |

### 3.1 图9：Seq2Seq 少样本故障检测（§2.2.2）

![图9 Seq2Seq 故障检测](../../../资料/img/09_Seq2Seq自编码器少样本故障检测.jpeg)

**自注意力 + GRU** 编码器压缩时序 → 编码向量同时驱动：**分类头**输出故障类别概率 + **解码器**重构输入。重构误差可用于未知故障发现，分类头用于已知故障类型识别，适合元器件/整机少样本场景。

### 3.2 图10：GAF 卷积特征提取（§2.2.2）

![图10 GAF 卷积特征提取](../../../资料/img/10_格拉姆角场卷积特征提取流程.jpeg)

健康状态时序经 GAF/MTF 图像化后，多路卷积核并行提取局部特征并聚合，供 CNN-LSTM 健康度分析使用。

### 3.3 图11：时序反转对比学习 RUL（§2.2.2）

![图11 对比学习 RUL 预测](../../../资料/img/11_时序反转对比学习RUL预测.jpeg)

预训练阶段用大量无标签数据 + 时序反转负样本对训练共享编码器；下游用少量失效样本微调解码器，输出 RUL。解决装备「失效样本稀缺」问题。

### 3.4 图13：大模型风险预测五步流程（§2.2.3）

![图13 大模型风险预测](../../../资料/img/13_大模型潜在质量风险预测方法.jpeg)

① DTWBA-K-means 构建时序知识库 → ② DTW 检索 Top-K 相似片段 → ③ STL 分解趋势/周期/残差 → ④ 组装 Prompt → ⑤ 大模型输出风险预测。这是创新点2 的核心工程流程。
