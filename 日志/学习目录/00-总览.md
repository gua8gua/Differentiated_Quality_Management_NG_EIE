## 本目录是什么

[`日志/学习目录/`](.) 是从 **32 篇参考文献 + 申报书第四章技术方案** 归纳出的**层次化学习材料**：

| 文件/文件夹 | 用途 |
|---|---|
| [01-学习路线.md](./01-学习路线.md) | 零基础分阶段学习目录（阶段 0–12） |
| [01-术语词典.md](./01-术语词典.md) | 遇到缩写先查这里 |
| [02-知识域/](./02-知识域/) | 按申报书章节系统学习（§1.1→§2.5） |
| [03-论文学习卡片/](./03-论文学习卡片/) | 读某篇 PDF 前的「预习卡」 |

## 读论文的正确姿势

1. **先读学习卡片**（`03-论文学习卡片/`）→ 知道本文讲什么、要先补什么
2. **不懂术语** → 查 [01-术语词典.md](./01-术语词典.md)
3. **想系统理解某技术** → 读 [02-知识域/](./02-知识域/) 对应章节，并对照第四章编号
4. **再打开 PDF** 精读方法和实验部分
5. **若要动手实现** → 看卡片末尾「若要实现可看」
