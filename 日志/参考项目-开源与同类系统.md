| 结论 | 说明 |

## 9. 与本项目的差距（选型时注意）

| 差距 | 说明 | 本项目仍需自建 |
|---|---|---|
| **领域** | 多为通用制造/PHM/ pharma QMS | 电子信息装备三类对象（整机/软件/元器件）指标树 |
| **标准** | 少项目原生对齐 **ISO 8000 + GB/T 34960.5** 草案 | D5/D6/D8 标准规范与符合性矩阵 |
| **方法链** | 几乎没有「GAN/扩散 + 共形预测 + SDE 多模态补全」一体开源 | 实验一完整流水线 |
| **图谱** | 制造 KG 多偏 CMMS/供应链 | ≥2 万实体装备质控图谱 + 增量 ≤7 天 |
| **智能体** | Agent 框架通用，缺装备质控博弈/共识 | 三类智能体 + 2.4 评测 |
| **数据** | 无脱敏装备真实集 | 合作单位数据 + 合成数据 |
| **许可** | MVTec 等非商业限制 | 研究/结题用途需单独合规审查 |
