## 1. 总览

本目录存放 **申报书第四章技术方案**（[索引](../日志/01-申报书技术方案.md)）方法验证用的**本地基准数据镜像**；六域 A–F 为辅助对照。

| 统计项 | 数值 |
|--------|------|
| 目录数 | 10 |
| 官方源直链成功 | 6 项 |
| 经工具/镜像成功 | 2 项（C-MAPSS→phmd，RAG→IndustrialGraphRAG） |
| **官方下载失败，已用兜底** | **2 项**（HAI、MVTec AD bottle） |
| 本地合成/生成 | 2 项（MCDM、HAI/MVTec 兜底） |
| 合计体积 | 约 10 GB（主要为 MIMII 阀门声学包） |

> **是否「电子信息装备数据」？** 多数条目是**跨领域算法基准**（如 MVTec 的瓶子/电缆、SECOM 半导体工艺），不是雷达/元器件专用集；用途是复现论文与开源工具链，**不能代替**合作单位脱敏装备数据。

**图例**

| 标记 | 含义 |
|------|------|
| ✅ | 已从官方/公开源成功获取 |
| ⚠️ | 官方下载失败，当前为**合成或替代数据**，需后续替换 |
| 🔧 | 本地脚本生成，无外部公开集 |

### 3.4 `04_vision_mvtec_bottle` — 工业视觉异常（通用制造，非电子装备） ⚠️

| 项 | 说明 |
|----|------|
| **领域定位** | **不是**电子信息装备专用数据。MVTec AD 面向**工业外观检验**通用 benchmark（15 类物体/纹理：Bottle、Cable、Transistor 等），与 [MVTec 官网说明](https://www.mvtec.com/company/research/datasets/mvtec-ad) 一致 |
| **为何纳入本项目** | 日志1 / 论文 [34] 工业视觉 QC；`projects/anomalib` 默认基准；验证域 B/E 的**视觉异常检测与 mask 标注**流程，而非模拟雷达/PCB 场景 |
| **预期内容** | 本地计划只保留 **Bottle** 单类（约 **148 MB**，不必下全库 4.9 GB） |
| **目录结构（官方）** | 每类含三个文件夹：`train/`（无缺陷训练图）、`test/`（含缺陷与正常测试图）、`ground_truth/`（异常区域像素级 mask） |
| **官方下载页** | https://www.mvtec.com/company/research/datasets/mvtec-ad |
| **推荐方式** | 在官网 **Download Dataset** 区选择 **Bottle (148 MB)** 单类链接（或全库）；部分环境需 **MVLogin** 登录后可见下载按钮 |
| **曾用脚本镜像（已失效）** | anomalib 旧链 `mydrive.ch/.../mvtec_anomaly_detection.tar.xz` → **HTTP 404** |
| **许可** | [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)（**禁止商业用途**） |
| **项目域** | B/E（视觉 QC 算法验证，非装备语义数据） |
| **本地状态** | ⚠️ **合成兜底** 约 2.3 MB（仅目录结构演示）；**应手动替换为官网 Bottle 148 MB 真实数据** |

**手动替换步骤（建议）**

1. 打开 [MVTec AD 下载页](https://www.mvtec.com/company/research/datasets/mvtec-ad)，下载 **Bottle** 压缩包并解压。  
2. 将解压后的 `bottle/` 目录放入 `datasets/04_vision_mvtec_bottle/`（覆盖当前合成内容）。  
3. 更新 `manifest.json` 中 `mvtec` 条目的 `note` 为「manual official bottle」。

## 5. 维护命令
